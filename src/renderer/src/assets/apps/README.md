# App Store logos

Put the official logo of each app in this folder and the App Store shows it instead of the plain icon.
Use these file names (png, svg, jpg or webp; square, about 128 x 128 or larger, any background):

- `nginx.png`
- `php.png`
- `pm2.png`
- `mysql.png`
- `redis.png`
- `nodejs.png`
- `composer.png`
- `supervisor.png`
- `postgresql.png`
- `server-copy.png` (optional, this one is not a product)

Official downloads: php.net/download-logos.php, pm2.keymetrics.io, mysql.com/about/legal/logos.html, redis.io/brand.
Restart `npm run dev` after adding a file.


The svg files here now (nginx, php, nodejs, python, java, docker, mongodb, composer, pm2, mysql, postgresql, redis) come unchanged from the devicon icon set (github.com/devicons/devicon, MIT licence). The logos themselves remain trademarks of their owners. Supervisor has no logo in that set and keeps the plain icon. A file you add with the same name replaces one of these.
