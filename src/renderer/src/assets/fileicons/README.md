# File type icons

These SVG files are copied unchanged from **Material Icon Theme** 5.40.0
(npm package `material-icon-theme`, https://github.com/material-extensions/vscode-material-icon-theme),
under the MIT License included here as `LICENSE`.

Which file name gets which icon is decided in `src/renderer/src/fileIcons.ts`.
To add one, copy the matching file from the package's `icons/` folder into this folder
and add the extension or name there.
